# Visitor Tracker

A Java Spring MVC based Visitor Tracking and Management System developed using Java, Spring MVC, JSP, MySQL, and Maven.

## Features
- Admin and User Login Authentication
- Visitor Entry Management
- Role-Based Access Control
- Dashboard Monitoring
- Visitor Record Storage and Retrieval
- Database Integration
- User-Friendly Interface

## Technologies Used
- Java
- Spring MVC
- JSP
- MySQL
- HTML
- CSS
- Maven

## Project Purpose
The Visitor Tracker application was developed to efficiently manage visitor information through a secure and interactive web application. It allows admins to monitor visitor data while users can manage and access their own records.

## Outcome
The system improved visitor data organization and tracking through secure authentication, dashboard management, and efficient record handling.

## How to Run the Project
1. Clone the repository
2. Open the project in Spring Tools Suite / Eclipse
3. Configure MySQL database
4. Run the project on Apache Tomcat Server
5. Open the application in browser
